# 🎵 Music Playlist Manager

Progetto per il corso di **Software Architecture Design** – A.A. 2025/2026.

Applicazione desktop in **Java** per la creazione e gestione di playlist musicali con riproduzione simulata e filtri avanzati, sviluppata seguendo il processo **Scrum**.

## 📋 Funzionalità principali

- Gestione tracce (CRUD): titolo, autore, durata, genere, anno
- Creazione e gestione playlist
- Riproduzione simulata: **sequenziale**, **shuffle**, **loop**
- Modifica playlist in tempo reale (anche durante la riproduzione)
- Operazioni undo/redo
- Tracce più riprodotte in home
- Creazione automatica di playlist per genere/anno
- Tag visivi (favourite, explicit, new release)
